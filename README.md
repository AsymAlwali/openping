# OpenPing – The Internet's Memory

A free, open-source API that watches the live internet and alerts you when websites change.

**Built in 100 hours. Live in public. Starting Monday.**

## Why OpenPing?
- Visualping/Hexowatch charge $500/month for change detection.
- Firecrawl is great for *getting* data. OpenPing is for *tracking* data.
- This is the missing piece for AI agents, RAG pipelines, and indie hackers.

## What it does:
- Fetches ANY webpage (bypasses Cloudflare bot blocks)
- Converts to clean LLM-ready markdown
- Detects changes instantly
- Sends webhook alerts
- Caches permanent snapshots
- Costs $0 to run
